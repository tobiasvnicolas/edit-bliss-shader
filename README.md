# Instrucciones para utilizar el shader

1. Necesitas optifine 1.20.1
2. Descarga la release más reciente del shader desde la sección de "Releases" en este repositorio.
3. Coloca el archivo .zip descargado en la carpeta "shaderpacks" dentro del directorio de Minecraft. Si no existe, créala.
4. Abre Minecraft con Optifine y ve a "Opciones" > "Configuración de video" > "Shaders".
5. Selecciona el shader que acabas de colocar en la carpeta "shaderpacks".

Este shader es un proyecto para la materia de computación gráfica de la universidad.
